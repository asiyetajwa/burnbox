# Burn Box

Send us the file you're afraid to open. A detonation chamber for small teams.

Upload a suspicious file or paste a suspicious link. Burn Box opens it inside a disposable sandbox on Vultr, records everything it tries to do, then burns the box. You get a plain-English verdict and a signed destruction receipt.

Built for the Vultr Agent Rush, Challenge 1: Blast Radius Zero.

## Status

Brand kit first: `docs/brand/`. The sandbox runner, web app and Vultr deployment follow.
